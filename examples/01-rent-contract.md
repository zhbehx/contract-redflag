# 案例：一份「处处是坑」的租房合同

## 用户输入

> 明天要签合同，帮我看看有没有问题。

```
房屋租赁合同
一、房屋坐落：某某小区 3 号楼 502 室。
二、租赁期限：自 2026 年 1 月 1 日起至 2026 年 12 月 31 日止。租期届满后自动续租一年。
三、租金：每月 4800 元，押一付三。
四、押金：支付押金 4800 元。租赁期满，乙方结清费用并将房屋交还甲方后，押金于退租时退还。
    如房屋有损坏，甲方有权扣除相应费用后退还。
五、费用承担：水电燃气费、物业费、取暖费由乙方承担。乙方应保持房屋整洁，
    退租时如不整洁，甲方有权收取清洁费。
六、房屋维修：租赁期间房屋及附属设施的维修由乙方负责。
七、甲方权利：甲方有权随时进入房屋进行检查或带人看房。甲方有权提前收回房屋。
八、转租：乙方不得转租。
九、违约责任：乙方提前退租的，押金不予退还。乙方逾期支付租金的，按日 5% 计收滞纳金。
    因乙方原因导致的一切损失由乙方承担。
```

## 三条最要命的，翻译成人话

### 1.「押金于退租时退还」+「扣除相应费用」

**翻译**：什么时候退、退多少、扣什么，全部由房东单方决定。

- 「退租时」可以是下周，也可以是三个月后
- 「相应费用」没有标准，他说墙面脏了要重刷，你就得认

**签字前要补**：
> 「退租验收合格后 3 个工作日内退还押金至乙方指定账户，逾期按日万分之五支付违约金。扣款项目及金额须经双方书面确认；自然损耗不视为损坏。」

### 2.「房屋及附属设施的维修由乙方负责」

**翻译**：水管爆了、热水器坏了、墙体裂了，全算你的。

这一条在法律上通常不能覆盖房屋主体结构和自然老化，但它会成为对方扣押金的依据。

**签字前要补**：
> 「主体结构及原有设施的自然老化由甲方负责维修或更换；因乙方人为损坏的，按维修发票金额承担。」

### 3.「按日 5% 计收滞纳金」

**翻译**：欠 4800 元租金，一天罚 240 元。一个月就是 7200 元，超过本金。

这个标准远超司法实践中认可的上限，但**在争议发生前，它就是你头上的刀**。

**签字前要补**：
> 「逾期支付租金的，按日万分之五计收滞纳金，且总额不超过欠付租金的 20%。」

## 还有一条容易被忽略的：自动续租

「租期届满后自动续租一年」——如果你到期想搬走但忘了书面通知，可能被再锁一年。

**签字前要补**：
> 「任一方可在到期前 30 日书面通知不续租；未通知的，按月续租。」

## 对照：一份规范合同跑出来是 0 分

把上面这些补齐后，同一套规则跑出来：

```
$ python scripts/scan_contract.py rent_ok.txt --type rent

风险分：0/100    相对规范：仍要核对缺失条款与附件
条款：高危 0 · 中危 0 · 提醒 0   缺失 0 条   （545 个汉字）
```

注意它是怎么变成 0 分的：**不是删掉了条款，而是给每个条款补上了「期限、标准、程序」**。

## 怎么跟房东谈（不撕破脸版）

别说「你这条违法」。说：

> 「这套合同是中介的模板吧？我想在补充条款里加三句话，就三句：押金退的期限、维修的分工、滞纳金的上限。其他都不动，您看行吗？」

关键信号：**对方愿不愿意在纸上补一句话**。

- 愿意 → 正常生意，可以签
- 说「都是这么签的」但愿意加 → 也可以签
- 一口回绝、不耐烦、说「不信我就别租」→ 这本身就是答案

## 这个案例说明了什么

1. **合同的危险不在写了什么，在没写什么。** 六条缺失项里，「押金退还期限」和「维修责任」任何一条出问题，都是几千块。
2. **同一个事实，写法决定风险。** 「维修由乙方负责」和「自然老化由甲方、人为损坏由乙方」，事实相同，风险完全不同。
3. **脚本给的是定位，不是结论。** 它告诉你第几条要看，看完怎么谈是你的事。

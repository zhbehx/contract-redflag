# 风险条款词典

每条：**原文常见写法 → 风险点 → 建议补充/确认的表述**。

> 以下为常见商业与实务经验，**不构成法律意见**。法定强制性规定以现行法律为准。

## 一、押金与退款（租房最高发）

| 原文写法 | 风险点 | 建议补充 |
| --- | --- | --- |
| 「押金于退租时退还」 | 没写期限，"退租时"可以是任何时间 | 「退租验收合格后 3 个工作日内退还至乙方指定账户」 |
| 「扣除相应费用后退还」 | "相应费用"无标准 | 「扣款项目及金额须经双方书面确认，未确认不得扣除」 |
| 「如有损坏照价赔偿」 | "照价"由房东单方认定 | 「自然损耗不视为损坏；赔偿金额按同期市场价或维修发票结算」 |
| 「押一付三」「押二付一」 | 押金越高，退不回时损失越大 | 明确押金总额与退还条件；保留转账凭证 |
| 「保持房屋整洁，否则扣押金」 | "整洁"无标准 | 「退租时乙方负责清空个人物品并清扫，除此之外不作扣款依据」 |
| 清洁费固定收取 | 可能高于实际成本 | 「清洁费按实际发生结算，最高不超过 X 元」 |

## 二、期限、续租与解约

| 原文写法 | 风险点 | 建议补充 |
| --- | --- | --- |
| 「租期届满自动续租一年」 | 想走时走不掉 | 「任一方可在到期前 30 日书面通知不续租」 |
| 「提前退租押金不退」 | 解约成本可能过高 | 「提前 30 日书面通知可解约，违约金不超过一个月租金」 |
| 「甲方有权提前收回房屋」 | 单方解约权，无补偿 | 「甲方提前收回须提前 60 日通知并支付一个月租金作为补偿」 |
| 「乙方不得提前解除」 | 单方禁止解约 | 争取对等条款或约定违约金上限 |
| 竞业限制期限长于法定期限 | 劳动合同：竞业限制最长 2 年 | 「竞业限制期限不超过 2 年，且须按月支付补偿」 |

## 三、单方权利

| 原文写法 | 风险点 | 建议补充 |
| --- | --- | --- |
| 「甲方有权进入房屋检查」 | 无通知即可进入 | 「甲方进入须提前 24 小时通知并取得乙方同意，紧急情况除外」 |
| 「公司有权根据经营需要调整岗位和薪资」 | 变相降薪调岗 | 「调整须经双方协商一致并书面确认，调整后薪资不低于原标准」 |
| 「乙方应服从公司的各项工作安排」 | 义务无限扩张 | 「工作内容以岗位说明书为准，重大变更须双方书面确认」 |
| 「公司可单方解除合同且无需补偿」 | 与法定情形冲突 | 明确列举解除情形，其余按法定标准补偿 |

## 四、费用与责任划分

| 原文写法 | 风险点 | 建议补充 |
| --- | --- | --- |
| 「物业费、取暖费由乙方承担」 | 金额可能过千 | 明确各项费用金额与承担方，写进合同 |
| 「水电燃气按表计费」 | 没写单价可能被加价 | 「按供水/供电/燃气公司标准单价结算，甲方不得加价」 |
| 「房屋维修由乙方负责」 | 结构性问题也归你 | 「主体结构及原有设施自然损坏由甲方维修；乙方人为损坏由乙方负责」 |
| 「设备损坏由使用方赔偿」 | 老旧设备自然损坏也算你 | 「设备自然老化由甲方维修或更换」 |
| 「加班不计入工作时间」 | 加班认定被排除 | 无效约定可能性高；保留打卡与工作记录 |

## 五、违约与滞纳金

| 原文写法 | 风险点 | 建议补充 |
| --- | --- | --- |
| 「逾期支付租金按日 5% 计收滞纳金」 | 远超常见标准 | 「按日万分之五（或不超过 LPR 的 4 倍）计收」 |
| 「违约金为合同总额的 30%」 | 可能过高 | 争取与实际损失挂钩，或设上限 |
| 「乙方违约须赔偿甲方全部损失」 | "全部损失"无边界 | 「赔偿以实际直接损失为限，不含间接损失」 |
| 「因乙方原因导致的一切责任由乙方承担」 | 概括条款 | 限定为「因乙方过错直接导致的损失」 |
| 「竞业违约金 X 万元」 | 可能高于补偿总额 | 确认补偿标准与违约金是否对等 |

## 六、模糊表述（最需要改写的一类）

| 模糊写法 | 问题 | 替换成 |
| --- | --- | --- |
| 「及时」「尽快」「合理期限内」 | 没有可执行标准 | 具体天数或工作日 |
| 「合理损耗」「正常使用痕迹」 | 由强势方解释 | 列举具体情形 |
| 「根据公司经营需要」 | 无限授权 | 限定为具体情形并加协商程序 |
| 「另行约定」「双方协商确定」 | 等于没有约定 | 现在就写清楚，或明确"未达成一致时不生效" |
| 「包括但不限于」 | 范围无边界 | 保留可以，但要给一个已知清单 |
| 「保持整洁」「爱护房屋」 | 无标准 | 删掉，改为具体义务 |

## 七、劳动合同专属高危项

| 原文写法 | 问题 | 应对 |
| --- | --- | --- |
| 试用期超过法定上限 | 3 年以上合同试用期最长 6 个月；1–3 年最长 2 个月；1 年以下最长 1 个月 | 要求改正 |
| 试用期工资低于转正后 80% | 法定下限 | 要求改正 |
| 约定「不缴社保」或「社保折现」 | 无效且违法 | 要求按规定缴纳 |
| 「自愿放弃加班费」 | 常见无效约定 | 保留工时证据 |
| 空白合同先签字 | 后续可填任意内容 | 拒绝，要求填写完整再签 |
| 违约金条款（除培训服务期与竞业限制外） | 一般不得约定由劳动者承担违约金 | 要求删除 |
| 培训服务期长于合理范围 | 服务期应与培训成本对应 | 确认培训费用凭证 |

## 八、怎么谈才不撕破脸

不要说「这条违法」，要说「这条能不能补一句」。三个模板：

1. **补充具体化**：「这条能不能加个期限？比如验收后 3 个工作日内。」
2. **对等化**：「甲方提前收房要提前 60 天，那我提前退租也提前 30 天，这样对等。」
3. **给台阶**：「我知道这是标准模板，我只需要在补充条款里加这一句，其他都不动。」

一个很有用的信号：**对方愿不愿意在合同上补一句**。愿意，说明是正常生意；一口回绝且不耐烦，本身就是信息。
